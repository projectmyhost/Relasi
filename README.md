# Relasi (RuangSuara)

Project web application dibangun menggunakan Next.js 14, React 18, TypeScript, dan Tailwind CSS.

## Getting Started

Pertama, install dependensi:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3001](http://localhost:3001) di browser Anda untuk melihat hasilnya.

## Build Production

Untuk build aplikasi:

```bash
npm run build
npm run start
```
